## Overview

This page documents the tasks, progress, and learning outcomes related to the Mechanical track of the robotics summer training program.

The Mechanical track focuses on understanding robot structure, mechanical design, mechanisms, materials, manufacturing methods, CAD modeling, 3D printing, assemblies, and the physical components used in robotics systems.

Each task has its own folder and README file containing the design process, project files, screenshots, results, challenges, and learning outcomes.

## Task Summary

### Task 1: Initial Mechanical Design for a Simple Robotic Dog

This task focused on creating an initial mechanical concept for a simple robotic dog.

The goal was to understand the basic mechanical principles that allow a robot to stand and walk, including body shape, leg design, joints, degrees of freedom, motor selection, torque, and expected mechanical problems.

[Open Task 1 Documentation](./Task-1-Initial-Mechanical-Design-for-a-Simple-Robotic-Dog)

### Task 2: Batman Logo Keychain Design Using SolidWorks

This task focused on creating a 3D keychain model using SolidWorks.

A Batman logo reference image was used to estimate the design shape and measurements. The design was sketched, extruded, exported as an STL file, and uploaded to GitHub with its project files and documentation.

[Open Task 2 Documentation](./Task-2-Batman-Logo-Keychain-Design-Using-SolidWorks)

### Task 4: Exploded View of the Robot

This task focused on assembling a robotic dog and creating a complete exploded view using SolidWorks.

The robot body, legs, servo motors, screws, and other components were positioned inside the assembly. The components were then separated into organized explode steps to clearly demonstrate their arrangement and assembly sequence.

Explode lines were added to show where the components connect, and the final exploded-view animation was exported, compressed, and embedded in the task documentation.

[Open Task 4 Documentation](./Task-4-Exploded-View-of-the-Robot)
